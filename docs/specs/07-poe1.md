# PoE 1 — porting the tools (v0.1 — draft)

Status: **draft**. Decisions are logged in [`open-questions.md`](./open-questions.md)
(P-series). Facts marked **[probe]** come from poe.ninja's docs or third-party sources and
must be confirmed by the PoE 1 probe (§8, step P0) before code relies on them.

## 1. Goal and scope

Make every PoE 2 economy tool available for **Path of Exile 1** through the existing game
switch, **ready for the 3.30 league launch (2026-11-13)** (decided, P3).

| Tool                 | PoE 2 spec                                          | PoE 1 work                                                     |
| -------------------- | --------------------------------------------------- | -------------------------------------------------------------- |
| Currency Speculation | [`01`](./01-currency-speculation.md)                | Same engine, chaos unit, PoE 1 thresholds (§5.1)               |
| Currency Flipping    | [`04-currency-flipping`](./04-currency-flipping.md) | PoE 1 exchange feed, PoE 1 hubs (§5.2); blocked if no feed     |
| Cheapest Currency    | [`04-cheapest-currency`](./04-cheapest-currency.md) | PoE 1 pay currencies from the probe (§5.3)                     |
| Sell Now             | [`06-sell-now`](./06-sell-now.md)                   | Same engine, chaos unit, divine becomes a sellable item (§5.4) |

Not covered:

- **Crafting Recipes**: it has no spec for PoE 2 yet. Its PoE 1 version is specified with it.
- **Hardcore, Ruthless, SSF, Standard**: softcore trade only, as in PoE 2 (Q3).
- **Stash items** (uniques, gems, maps, bases, beasts and so on, from poe.ninja's
  `stash/…/item/overview`): exchange items only in v1 (decided, P2).

## 3. Units (decided, P1)

PoE 1's economy runs on **chaos**: a divine is worth hundreds of chaos and most exchange
items are worth less than one divine.

- **PoE 1 prices and volumes are in chaos**, with the **divine value shown next to them**
  (secondary, smaller) where a price is displayed. PoE 2 stays divine-only (Q10). The
  "prices in divine" rule becomes **per game**: each game declares a primary and a
  secondary unit (§6.1).
- All thresholds that carry a unit (min price, min volume, min value per leg, budget) get a
  **PoE 1 default in chaos** (§5). Unit-free settings (multipliers, %, confidence, days) are
  shared.
- Divine is an **item** in PoE 1: it is listed, speculated on and can be flagged by Sell Now
  (it is the unit in PoE 2, so it is excluded there). Chaos is the unit and is never listed.
- The flipping tool keeps in-game ratios in their own currencies (F7). Its profit is in %.

## 4. Data sources (PoE 1)

### 4.1 poe.ninja — exchange overview and details

Documented in poe.ninja's API docs (2026-10-24):

- `GET /poe1/api/economy/leagues`: `[{ id, name }]`, first = current challenge league.
- `GET /poe1/api/economy/exchange/current/overview?league={id}&type={type}`: **same response
  shape as PoE 2** (`core.primary`, `core.rates`, `lines[]` with `primaryValue`,
  `volumePrimaryValue`, `maxVolumeCurrency`, `maxVolumeRate`, `sparkline`, plus `items[]`).
- PoE 1 `type` values (3.29): `Currency, Fragment, Runegraft, AllflameEmber, Tattoo, Omen,
DjinnCoin, Ducat, EnshroudingCrystal, DivinationCard, Artifact, Oil, DeliriumOrb, Scarab,
Astrolabe, Fossil, Resonator, Essence`. The list changes each league (league-mechanic
  categories come and go), so it is read from a per-game constant updated with each new
  league, and a category missing from the reference league counts as "no reference".
- PoE 1 overviews refresh about every **15 minutes** (PoE 2: hourly). We still fetch
  **hourly** (policy: no faster than needed).

To verify in P0 **[probe]**:

- `core.primary` for PoE 1 (expected `chaos`; if it is `divine`, convert with
  `core.rates.chaos`) and the keys of `core.rates`.
- `GET /poe1/api/economy/exchange/current/details?league=…&type=…&id={detailsId}`: does
  it exist for PoE 1 with full daily history per pair (needed for backfill, daily history
  and Cheapest Currency)? It is undocumented for PoE 2 too.
- Whether `current` routes answer for an ended league (3.28 Mirage).
- Item counts per category and how many pass the liquidity thresholds (request budget §6.3).
- The `/poe1/data` dump format, as the backfill fallback.

The documented `stash/current/currency/overview` route (pay/receive from listings, in chaos)
is **not used**. The exchange overview covers the same items from real trades.

### 4.2 GGG currency-exchange feed (flipping only)

GGG's official API exposes `GET /currency-exchange[/<realm>][/<id>]` (OAuth scope
`service:cxapi`, realm omitted = PoE 1 PC, `poe2` = PoE 2). Our PoE 2 source is a public,
no-auth mirror of that route: `web.poecdn.com/api/currency-exchange/poe2/{hourEpoch}`.

P0 probes the PoE 1 candidates (unverified **[probe]**):

1. `https://web.poecdn.com/api/currency-exchange/{hourEpoch}`
2. `https://web.poecdn.com/api/currency-exchange/pc/{hourEpoch}`

It records the status, the digest shape (expected identical to `05-ggg-exchange-api.md`),
the league names present, and the hub ids by number of markets.

- **If neither answers**: PoE 1 flipping is **blocked**. The fallback is an OAuth app
  (`service:cxapi`), which the F2 decision ("no OAuth app") rules out for now, so it needs
  a new decision (open question P-O1). The other three tools do not depend on this feed.
- Base item ids → names: RePoE PoE 1 export (`https://repoe-fork.github.io/base_items.json`,
  **[probe]**), committed as `packages/data-job/data/exchange-base-items-poe1.json` by the
  base-items probe with a `game` input.

## 5. Tool by tool

### 5.1 Currency Speculation (spec 01)

Engine, actions, confidence, positions, basket and alerts are **unchanged**. Differences:

- Prices `R(t)`, `N(t)` in chaos. The engine is unit-free (ratios), so only inputs change.
- **Market factor** `f(d)` = median `N/R` over liquid items, priced in chaos. It absorbs a
  change in chaos's own value between leagues, like divine's in PoE 2.
- **Divine Orb is a row** (its chaos price moves over a league). Chaos is excluded from
  the table and from the market factor.
- Default filters, PoE 1 (starting values, tuned by the backtest):
  - min volume **1,000 c/day** (also required for BUY NOW);
  - min price **1 c**;
  - liquidity saturation (confidence) **10,000 c/day**;
  - basket budget in chaos, with a divine-equivalent hint.
- **League-mechanic items** (e.g. Allflame Embers in 3.29) have no reference in the next
  league: NEUTRAL with "no reference" (spec 01 §6). Core items that were league-only and
  became core get a reference only if the previous league had them.
- **Backtest before launch**: run `backtest` on 3.29 vs 3.28 (days 7–35, 14-day hold) to
  check `premiumDamping` and the BUY NOW threshold for PoE 1. Results go in the decisions
  log.
- Positions, basket and alerts are stored **per game and league**.

### 5.2 Currency Flipping (spec 04-currency-flipping)

Requires the PoE 1 feed (§4.2). If it exists:

- **Hubs from the probe**: any currency present in at least 100 item markets of the league in
  an hour (PoE 2 has three: chaos ≈ 490, exalted ≈ 480, divine ≈ 390). Expected PoE 1 hubs:
  **chaos and divine**, maybe exalted. With 2 hubs, cross-pair flips are chaos → X → divine →
  chaos and the reverse. Spread flips work on any hub market.
- Engine unchanged (VWAP margins, recurrence, outlier cap); hub set is a per-game parameter.
- Value filter per leg in **chaos**: starting value **20,000 c / 24 h**, roughly the PoE 2
  default of 120 div at current rates. Calibrated on the first days of data, like F16.
- Window cache per game (`exchange-window/poe1/<league>/…`). The digest is fetched **once
  per hour for both games** if one feed holds both (same response, filtered by league).
  Otherwise there is one extra request per hour.
- Gold stays deferred (F8). PoE 1's exchange also charges gold, with its own costs.
- Ships as **beta** with the same "not verified in-game" notice until one PoE 1 margin is
  checked in game.

### 5.3 Cheapest Currency (spec 04-cheapest-currency)

- Pay currencies = the PoE 1 hubs from the probe (expected **chaos, divine**, + exalted if
  its pairs carry volume). `PAY_CURRENCIES` becomes per game.
- Per-pair rates from the PoE 1 details route (daily) + busiest pair from the hourly overview,
  as in PoE 2. If the PoE 1 details route does not exist **[probe]**, the tool falls back
  to the hourly overview's busiest pair only. The verdict needs two pairs, so the tool is
  then **not shipped for PoE 1** (logged, revisit).
- Costs in chaos, divine value alongside. Whole-unit rounding matters more in PoE 1: paying a
  whole divine for a 40 c item wastes most of it. The waste and "same price buys N'" hints
  carry this, unchanged.
- Verdict thresholds: ≥ 5 % cheaper (shared) and the chosen pair traded **≥ 200 c/day**.

### 5.4 Sell Now (spec 06-sell-now)

Agreed v1 behaviour (from the PoE 2 session, applies to both games):

- Scope: every liquid exchange item. Verdicts **SELL NOW / SELL SOON / HOLD** (HOLD hidden by
  default). Ranking: expected % loss if held × confidence.
- **Peak signal**: the reference curve peaks around today (or within 7 days → SELL SOON with
  the sell day) and then falls ≥ 15 % over the next 14 days.
- **Falling signal**: ≥ 15 % down over 7 days **and** the reference does not rise over the
  next 14 days. 1- and 3-day changes are shown but trigger nothing.
- The "still rising" guard was dropped (backtest: neutral to harmful). The 3- and 7-day
  trend is shown instead.
- Separate tool sharing the speculation helpers (`packages/shared/src/sell-now/`). Alerts
  are not in v1.

PoE 1 differences:

- Prices in chaos. **Divine is a sellable item**, and chaos is excluded from the market move
  (`marketChanges`) instead of divine.
- Liquidity filter: same PoE 1 defaults as Speculation (§5.1).
- Re-run `backtest-sell` on 3.29 vs 3.28 to confirm the 15 % / 14-day and 7-day thresholds
  for PoE 1. Log the result. Different defaults per game are allowed.

## 6. Shared changes

### 6.1 Game configuration (`packages/shared/src/games.ts`)

One `GameEconomy` record per game replaces the PoE 2 constants scattered in the code:

```ts
interface GameEconomy {
  game: Game;
  ninjaPrefix: '/poe1' | '/poe2';
  unit: 'chaos' | 'divine'; // primary price unit
  secondaryUnit: 'divine' | null; // shown alongside (PoE 1)
  exchangeTypes: readonly string[]; // poe.ninja exchange `type` values, per league
  hubs: readonly string[]; // flipping hubs = Cheapest Currency pay currencies
  exchangeFeedUrl: string | null; // GGG digest base URL, null = no flipping
  repoeBaseItemsUrl: string;
  defaults: { minPrice: number; minVolume: number; liquiditySaturation: number; ... };
}
```

- `ENABLED_GAMES` gets `'poe1'` once Speculation works on PoE 1 data. Each registry entry
  lists `games: ['poe2', 'poe1']` only when that tool is ready for PoE 1. The others show
  greyed out for PoE 1 (existing behaviour).
- The game switch keeps the last chosen game (settings). Default stays PoE 2.

### 6.2 Site data and schemas (`packages/shared/src/site-data.ts`)

- Paths are already per game: `poe1/leagues.json`, `poe1/<league>/current.json`,
  `history/<ExchangeType>.json`, `fx.json`, `pairs.json`, `flips.json`.
- Values are stored in the **game's primary unit**. Comments and field docs that say
  "divine" become "primary unit". `current.json` gets a `unit` field, and `rates` becomes
  `units per 1 primary` with the game's keys (PoE 1: at least `divine`).
- `fx.json` for PoE 1: `[[day, chaosPerDivine]]` (shape per game, zod-validated).
- The exchange type enum becomes per game (union of both lists for the schema, labels per
  game).

### 6.3 Data job

- `run.ts` loops over `ENABLED_GAMES` → `getTrackedLeagues(game)`, with the same steps:
  - hourly overviews;
  - once-per-league backfill;
  - daily details pass;
  - flips (if the game has a feed);
  - icons.
- Store layout on the `data` branch: `poe1/<league>/history/*.csv`, `fx.csv`, `pairs/*.csv`,
  `meta.json`. CSV columns are renamed to unit-neutral names (`price`, `volume`) for new
  files. Existing PoE 2 files keep their headers (read by position, or migrated in one
  commit).
- **Request budget**: PoE 1 hourly = 18 overviews. The daily details pass grows with liquid
  PoE 1 items (divination cards and scarabs alone are several hundred). Cap it with the
  backfill/details liquidity threshold (starting value **≥ 300 c/day**). Check the
  total job time against the 60-minute workflow timeout from probe item counts.
  If needed, the PoE 1 daily pass is spread over several hourly runs.
- Same `USER_AGENT`, throttling and "keep last good data" behaviour. A PoE 1 failure
  must not block PoE 2 publishing (per-game try/catch, workflow still fails loudly).
- `dev-data` and `backtest` take a `--game` option.

### 6.4 Web

- Price display components (`Div` and similar) become unit-aware: primary amount + optional
  secondary hint (`120 c · 0.6 div`). Formatting rules for chaos: integers ≥ 10 c, one
  decimal below.
- Settings and filters are stored per game (thresholds have different units).
- Home "Top opportunities" widget uses the selected game.

## 7. Edge cases

- **League gap** (Nov 9–13): no selectable PoE 1 league → notice with the next start date.
- **Launch day**: day 0–3 low confidence (unchanged). The reference 3.29 must be fully
  backfilled before Nov 13.
- **New category** in 3.30 (league mechanic): added to `exchangeTypes` in the 3.30 league PR.
  Items have no reference.
- **Category removed**: kept for the reference league's history files only.
- **Chaos-priced cheap items**: `primaryValue` below 1 c is common (e.g. many div cards).
  Min price filter defaults to 1 c, adjustable down to 0.
