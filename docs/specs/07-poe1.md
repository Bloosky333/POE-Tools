# PoE 1 — the tools for Path of Exile 1 (v1.0 — implemented)

Decisions are logged in [`open-questions.md`](./open-questions.md) (P-series). Facts below
were verified by the PoE 1 probe of 2026-10-24 (`pnpm probe:poe1`, fixtures in
`fixtures/poe1/`, summary in `fixtures/poe1/SUMMARY.md`).

## 1. Goal and scope

Every economy tool runs for **Path of Exile 1** through the game switch, **ready for the
3.30 league launch (2026-11-13)** (P3).

| Tool                 | Spec                                                | PoE 1 differences                                            |
| -------------------- | --------------------------------------------------- | ------------------------------------------------------------ |
| Currency Speculation | [`01`](./01-currency-speculation.md)                | Chaos unit, PoE 1 liquidity thresholds (§5.1)                |
| Sell Now             | [`06-sell-now`](./06-sell-now.md)                   | Chaos unit, divine is a sellable item (§5.4)                 |
| Currency Flipping    | [`04-currency-flipping`](./04-currency-flipping.md) | PoE 1 feed, hubs chaos + divine (§5.2)                       |
| Buy With / Sell For  | [`04-buy-with-sell-for`](./04-buy-with-sell-for.md) | Pays with chaos or divine (§5.3); page built for both games  |
| Crafting Recipes     | [`08-crafting-recipes`](./08-crafting-recipes.md)   | Chaos unit, PoE 1 mods / bases / crafting items (spec 08 §7) |

Not covered: Hardcore, Ruthless, SSF and
Standard (softcore trade only, Q3); stash items — uniques, gems, maps, bases… (P2).

| League (`id`)         | Version | Start (UTC)      | End (UTC)        | Role                                       |
| --------------------- | ------- | ---------------- | ---------------- | ------------------------------------------ |
| 3.30 (`poe1-3-30`)    | 3.30    | 2026-11-13 21:00 | —                | Selectable, reference Allflame             |
| Allflame (`allflame`) | 3.29    | 2026-07-24 20:00 | 2026-11-09 21:00 | Reference of 3.30; reference Mirage        |
| Mirage (`mirage`)     | 3.28    | 2026-03-06 20:00 | 2026-07-20 21:00 | Tracked for backtests only (`track: true`) |

- poe.ninja names the 3.29 league **`Allflame`** (also the feed's league name); its
  `/poe1/api/economy/leagues` lists `Allflame`, `Hardcore Allflame`, `Standard`, `Hardcore`.
- poe.ninja still serves an **ended league** (Mirage: overview and details answered three
  months after its end) although it no longer lists it. The data job therefore fetches
  ended leagues anyway, and **backfills a league once more after its end** so the reference
  curve covers the whole league (Allflame: after 2026-11-09).
- **3.30's name is not announced** (ExileCon, early November). Its entry has
  `ninjaNameAuto: true`: once its start has passed, the data job uses poe.ninja's current
  challenge league (first listed, not Hardcore/Ruthless/SSF/Standard, not a tracked league)
  and warns "set its name in leagues.ts". Updating `name`/`ninjaName` (and the start, if it
  moves) in `packages/shared/src/leagues.ts` is the only manual step; the slug `poe1-3-30`
  stays, so stored data keeps its path.
- Until a league starts, PoE 1 tool pages show a notice with the start date instead of
  data; the top bar shows no league day and no freshness.
- Day alignment unchanged (UTC calendar day − start day). Allflame history starts at day 1
  (2026-07-25).

## 3. Units (P1)

- PoE 1 prices and volumes are in **chaos** (poe.ninja `core.primary = "chaos"`,
  `core.rates = { divine: 0.003046 }` → 328 c per divine on 2026-10-24). The divine value is
  shown next to prices (`Amount`, converted at today's rate).
- Chaos is the unit and is never listed; **Divine Orb is an item** (speculated on, can be
  flagged by Sell Now), mirroring PoE 2 where divine is the unit.
- Unit-carrying thresholds live in `ECONOMY[game]` (`packages/shared/src/games.ts`).
  PoE 1 starting values, chosen from the probe's item counts (spec §9):

  | Setting                                 | PoE 2    | PoE 1    | PoE 1 items passing (probe) |
  | --------------------------------------- | -------- | -------- | --------------------------- |
  | Min volume (BUY NOW, market measures)   | 5 div    | 1,000 c  | ~175 / 555                  |
  | Min price (market measures, filter)     | 0.05 div | 1 c      |                             |
  | Liquidity saturation (confidence)       | 50 div   | 15,000 c |                             |
  | Details history threshold (data job)    | 2 div    | 300 c    | ~280 / 555                  |
  | Flip: published min value per leg       | 10 div   | 2,000 c  |                             |
  | Flip: page default min value per leg    | 120 div  | 20,000 c |                             |
  | Buy/Sell: min volume of the chosen pair | 1 div    | 200 c    |                             |

  Unit-free settings (multipliers, %, days, confidence weights) are shared.

## 4. Data sources (verified)

### 4.1 poe.ninja

- `GET /poe1/api/economy/leagues`, `/poe1/api/economy/exchange/current/overview` and
  `/details`: **same shapes as PoE 2** (`03-poe-ninja-api.md`), values in chaos.
- Exchange types (3.29): `Currency, Fragment, Runegraft, AllflameEmber, Tattoo, Omen,
Ducat, EnshroudingCrystal, DivinationCard, Artifact, Oil, DeliriumOrb, Scarab, Astrolabe,
Fossil, Resonator, Essence` (`POE1_EXCHANGE_TYPES`). `DjinnCoin` is documented but empty
  and left out. 555 items; league-mechanic categories change each league (update the list
  with the league PR).
- Details: per item, pairs **chaos** and **divine** only, full daily history (Allflame: 92
  points). The fx series (divine per chaos) comes from the Chaos Orb's own details, as PoE
  2's comes from the Divine Orb's.
- PoE 1 overviews refresh ~every 15 min upstream; we still fetch hourly.
- Data dumps (`/poe1/data`): not needed — the details route covers ended leagues.

### 4.2 GGG currency-exchange feed

- `GET https://web.poecdn.com/api/currency-exchange/{hourEpoch}` (no realm segment;
  `/pc/` and `/poe1/` answer 404). Same digest as PoE 2 (`05-ggg-exchange-api.md`); leagues
  `Allflame` (~775 markets/hour, ~600 traded), Standard, Hardcore, Ruthless and private
  leagues, filtered by exact name.
- Hubs by markets (3 hours): chaos `CurrencyRerollRare` 1,631, divine `CurrencyModValues`
  592, then ≤ 11 (exalted `CurrencyAddModToRare`: 7) → **hubs = chaos, divine** (P-O5).
- Base item names: RePoE PoE 1 export (`https://repoe-fork.github.io/base_items.json`), all
  912 ids named → `packages/data-job/data/exchange-base-items-poe1.json` (regenerate with
  the probe workflow, `source: base-items`, `game: poe1`).

## 5. Tool by tool

### 5.1 Currency Speculation

Engine unchanged; `engineSettingsFor(game)` gives the unit (excluded from the table and the
market factor), min volume/price and liquidity saturation. The market factor absorbs a
change in chaos's own value between leagues. League-mechanic items (e.g. Allflame Embers)
have no reference in the next league → NEUTRAL "no reference".

### 5.2 Currency Flipping

Same engine with `flipSettingsFor(game)`: hub set and value unit per game. Hub values are
derived from the hub ↔ hub markets of each hour (chaos ↔ divine in PoE 1), so values per
leg are in chaos. With two hubs, cross-pair flips are chaos → X → divine → chaos and the
reverse. Window cache per game (`exchange-window/poe1/<league>/`). Beta notice unchanged.

### 5.3 Buy With / Sell For (formerly Cheapest Currency)

Built in this milestone for both games (`apps/web/src/tools/exchange-pair/`, engine
`packages/shared/src/best-pair/`), per `04-buy-with-sell-for.md`: pay currencies = the
game's hubs. Whole-unit rounding matters most in PoE 1 (one divine for a 40 c item); the
"same price buys N" hint shows it.

### 5.4 Sell Now

`sellSettingsFor(game)` (thresholds shared, liquidity saturation per game);
`marketChanges` excludes the game's unit. Divine can be flagged in PoE 1.

Backtest Allflame vs Mirage (P10): flagged items beat holding only slightly in PoE 1
(peak calls ×0.96 vs the market after 14 days, against ×0.88 in PoE 2). The page says so
for PoE 1; thresholds are kept and re-checked on 3.30 data.

## 6. Implementation

- **Shared** (`packages/shared`): `ECONOMY`, `CORE_CURRENCIES`, `EXCHANGE_TYPES[game]`,
  `isExchangeType`, `ALL_EXCHANGE_TYPES`; site files store values in the game's unit
  (`current.json` has `unit` and `rates` per 1 unit; `fx.json` lists its `currencies`).
- **Data job**: `main.ts` runs `runJob` per enabled game (a failing game does not block the
  other; the job still fails). Store layout `poe1/<league>/…` on the `data` branch; CSV
  headers name the unit (`price_c`, `divine_per_c`), PoE 2 files are byte-identical.
  `dev-data` writes local site data for both games (PoE 1 from `fixtures/poe1/`).
- **Web**: `useLeagueData().unit` / `unitInfo(game, current)`, `Amount` (replaces `Div`),
  filter defaults per game, switching game selects that game's default league.

## 7. Edge cases

- League gap (Nov 9–13): 3.30 not started → notice; Allflame keeps being followed as a
  reference (ended → re-backfilled once).
- New categories in 3.30: added to `POE1_EXCHANGE_TYPES` in the 3.30 league PR; their items
  have no reference.
- Items under 1 c (many divination cards): below the default min price, still listed with
  the filter at 0.
